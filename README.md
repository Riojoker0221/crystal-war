# 晶核战争 · Crystal War

统一像素画风的浏览器即时战略游戏，当前版本 **0.3.0**。支持四阵营、三档 PVE 和真实双人对战。

**[在线游玩](https://crystal-war.onrender.com)** · [游戏源码](https://github.com/Riojoker0221/crystal-war)

## 游玩

- 直接打开在线网址即可游玩；双人模式由一人创建房间，另一人选择自己的阵营后输入房间码加入。
- 安装 Node.js 22 或更新版本，运行 `npm start`，浏览器打开 `http://localhost:8787`。
- Windows 可双击 `启动游戏.cmd`，启动器会打开可用的游戏地址。
- `晶核战争-双击游玩.html` 可直接离线运行单人 PVE；双人对战需要双方访问同一个游戏服务器，通过房间码加入。

## 玩法

普通模式不限时，直到一方投降或全部主基地被摧毁。限时模式最多 10 分钟，第 8 分钟激活中央晶核，独占 45 秒可提前获胜，时间到则按战场得分结算。

左键选择或框选，右键移动、攻击或采矿；A 后左键攻击移动。方向键或中键拖动移动地图，滚轮缩放，点击小地图跳转。游戏内设操作手册、建筑前置树和技能说明。

地图为 2400×1520，18 处分散的有限晶矿会随开采缩小直至枯竭。工兵与战斗单位分别管理；主基地可缓慢迁移，第二基地和人口研究能提高人口上限。四阵营拥有专属研究和终极机制，包括人类爆破选区、机械超频、精灵庇护与传送、虫群召唤与狂潮。

详细数值见 [使用说明](使用说明.md) 和 [阵营机制与研究清单](阵营机制与研究清单.md)。

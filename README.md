# 晶核战争 · Crystal War

简洁统一几何画风的浏览器即时战略游戏，当前版本 **0.2.2**。支持四阵营、三档 PVE 和真实双人对战。

**[在线游玩](https://crystal-war.onrender.com)** · [游戏源码](https://github.com/Riojoker0221/crystal-war)

## 游玩

- 直接打开在线网址即可游玩；双人模式由一人创建房间，另一人选择自己的阵营后输入房间码加入。
- 安装 Node.js 22 或更新版本，运行 `npm start`，浏览器打开 `http://localhost:8787`。
- Windows 可双击 `启动游戏.cmd`，启动器会打开可用的游戏地址。
- `晶核战争-双击游玩.html` 可直接离线运行单人 PVE；双人对战需要双方访问同一个游戏服务器，通过房间码加入。

## 玩法

普通模式不限时，直到一方投降或全部主基地被摧毁。限时模式最多 10 分钟，第 8 分钟激活中央晶核，独占 45 秒可提前获胜，时间到则按战场得分结算。

左键选择或框选，右键移动、攻击或采矿；A 后左键攻击移动。方向键或中键拖动移动地图，滚轮缩放，点击小地图跳转。游戏内设操作手册、建筑前置树和技能说明。

地图为 2400×1520，18 处分散的有限晶矿会随开采缩小直至枯竭。工兵与战斗单位分别管理；主基地可缓慢迁移，第二基地和人口研究能提高人口上限。四阵营拥有专属研究和终极机制，包括人类爆破选区、机械超频、精灵庇护与传送、虫群召唤与狂潮。

详细数值见 [使用说明](使用说明.md) 和 [阵营机制与研究清单](阵营机制与研究清单.md)。

## 检查与构建

```sh
npm test
npm run build
```

无需安装第三方运行依赖。`public/app.js`、`public/engine.js`、`public/camera.js` 和 `public/worker-art.js` 为源文件；构建命令生成网页使用的脚本和离线单文件。0.2.1 的49项自动检查及模拟场景已通过；0.2.2 工兵造型更新另通过真实渲染预览与6项客户端检查，仍需后续真人对局调整平衡。

## Render 免费部署

2026年11月3日已部署至独立 Render Web Service，使用 Docker 与 **Free** 实例，未启用付费方案。仓库附带 `Dockerfile` 和 `render.yaml`；健康检查路径为 `/api/health`，服务读取 `PORT`，`MAX_ROOMS` 默认 30。

Render 免费实例闲置约15分钟后会休眠，唤醒可能需要约50秒或更久。对局房间仅保存在服务器内存，服务重启会结束现有房间。运行单实例即可；当前没有跨实例同步或对局持久化。

公网已验证健康接口、资源访问、双方创建加入及选阵营、共享对局推进、工兵处死权限与人口、基地迁移、投降结算及异常身份拒绝。完整检查范围见 [验证与发布状态](验证与发布状态.md)。仓库不包含账号凭据。

## 0.2.1 更新

双人1v1的基地分别位于左右两侧，纵向位置独立随机；起始晶矿随基地移动，避开障碍与其他矿区。PVE开局位置不变。主界面删除装饰性英文、难度副标题和重复提示；战斗中的说明、技能解释和快捷键保留。

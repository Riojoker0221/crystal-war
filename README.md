# 晶核战争 · Crystal War

简洁统一几何画风的浏览器即时战略游戏，当前版本 **0.2.0**。支持四阵营、三档 PVE 和真实双人对战。

## 游玩

- 安装 Node.js 22 或更新版本，运行 `npm start`，浏览器打开 `http://localhost:8787`。
- Windows 可双击 `启动游戏.cmd`，启动器会打开可用的游戏地址。
- `晶核战争-双击游玩.html` 可直接离线运行单人 PVE；双人对战需要双方访问同一个游戏服务器，通过房间码加入。

## 玩法

普通模式不限时，直到一方投降或全部主基地被摧毁。限时模式最多 10 分钟，第 8 分钟激活中央晶核，独占 45 秒可提前获胜，时间到则按战场得分结算。

左键选择或框选，右键移动、攻击或采矿；A 后左键攻击移动。方向键或中键拖动移动地图，滚轮缩放，点击小地图跳转。游戏内设操作手册、建筑前置树和技能说明。

地图为 2400×1520，18 处分散的有限晶矿会随开采缩小直至枯竭。工兵与战斗单位分别管理；主基地可缓慢迁移，第二基地和人口研究能提高人口上限。四阵营拥有专属研究和终极机制，包括人类爆破选区、机械超频、精灵庇护与传送、虫群召唤与狂潮。

详细数值见 [使用说明](使用说明.md) 和 [阵营机制与研究清单](阵营机制与研究清单.md)。

## 检查与构建

```sh
npm test
npm run build
```

无需安装第三方运行依赖。`public/app.js`、`public/engine.js` 和 `public/camera.js` 为源文件；构建命令生成网页使用的脚本和离线单文件。46 项自动检查及模拟场景已通过，仍需后续真人对局调整平衡。

## Render 免费部署

仓库附带 `Dockerfile` 和 `render.yaml`。在 Render 新建 Web Service，选择本仓库及 Docker 运行环境，实例类型选择 **Free**，健康检查路径为 `/api/health`。服务读取 `PORT`，`MAX_ROOMS` 默认 30。

Render 免费实例闲置后会休眠，首次访问可能等待启动。对局房间仅保存在服务器内存，服务重启会结束现有房间。运行单实例即可；当前没有跨实例同步或对局持久化。

公开服务应验证健康接口、两端创建加入、采矿指令、技能释放、断线暂停和投降结算。仓库不包含账号凭据。
